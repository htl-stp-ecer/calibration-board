# Firmware coding conventions

Applies to all C code under `Firmware/` **except** `Firmware/Core/`,
`Firmware/Drivers/`, and `Firmware/lib/` — those are STM32CubeMX-generated or
third-party and follow their upstream styles.

## Folder layout

```
Firmware/
├── Core/                     # STM32CubeMX-owned. Hands off (regenerates).
├── Drivers/                  # ST HAL + CMSIS. Hands off (regenerates).
├── app/                      # Application logic (state machines, glue).
│   ├── inc/                  # Public headers
│   └── src/                  # Implementations
├── drivers/                  # Project-owned hardware drivers.
│   └── <chip>/
│       ├── inc/<chip>.h      # Public API
│       └── src/<chip>.c
├── lib/                      # Third-party (submodules, vendored libs).
└── scripts/                  # Build / flash / debug helpers.
```

Rule of thumb: **capitalised folders are ST-generated, lowercase folders are
ours**. New code goes into lowercase.

## Naming

| Kind | Style | Example |
|---|---|---|
| Functions, variables | `snake_case` | `bno08x_read_quat()` |
| Module-public API | `<module>_` prefix | `bno08x_init()`, `app_main()` |
| Module-internal | `static`, no prefix | `static void parse_report(...)` |
| Types | `snake_case_t` | `bno08x_status_t` |
| Macros, constants | `UPPER_SNAKE` | `BNO08X_MAX_FRAME` |
| Enum values | `UPPER_SNAKE`, type-prefixed | `BNO08X_OK` |
| Files | lowercase, match module name | `bno08x.c`, `bno08x.h` |

Never `typedef` away pointers (no `bno08x_t *` hidden as `bno08x_handle`) —
explicit pointers read better.

## Headers

- Use `#pragma once`, not include guards. GCC supports it, less boilerplate.
- Public API only in `inc/`. Internal helpers in `src/`, optionally as
  `<module>_priv.h` next to the `.c`.
- Forward-declare in headers where possible; full `#include` only when the
  header needs the type's layout.
- One module = one `.c` + one `.h`. If a `.c` grows beyond ~500 lines, split.

## Functions and state

- Everything file-local is `static`. If something isn't in the public header,
  it must be `static`.
- No global variables outside of HAL-generated handles in `Core/`. Module
  state goes in a `static` struct inside the `.c`.
- Functions return `0` on success and negative `errno`-style codes on failure,
  or a dedicated `<module>_status_t` enum (preferred when codes are
  module-specific). Pick one per module and stick to it.
- Out-parameters via pointer, never by returning structs by value (varies
  across ABIs and copies on Cortex-M).

## main.c and USER CODE markers

- `Core/Src/main.c` is regenerated by CubeMX. The `/* USER CODE BEGIN ... */`
  markers are the only safe place for hand edits — anything outside gets
  overwritten.
- Keep `main.c` thin: peripheral init (CubeMX does this) + one call to
  `app_main()` in `USER CODE BEGIN 2`. Real logic lives in `app/`.
- Don't put driver-level code into `USER CODE` blocks. Add a module under
  `drivers/<chip>/` and call it from `app/`.

## Comments

- Default: no comments. Names should carry the meaning.
- Write a comment only when the **why** is non-obvious: a hidden constraint
  from a datasheet, a workaround for a known erratum, a subtle ordering
  requirement. Reference the source (`§7.3.2 of DS13855`) when relevant.
- Don't comment what the code does. Don't reference tickets, PRs, or
  "added for X" — that's git/PR territory.

## Includes order

```c
#include "this_module.h"        /* own header first — verifies it's self-contained */

#include <stdint.h>             /* C standard library */
#include <string.h>

#include "main.h"               /* HAL / ST */
#include "stm32f7xx_hal.h"

#include "sh2.h"                /* third-party */

#include "app.h"                /* other project modules */
```

Blank line between groups.

## Build hygiene

- Build artifacts go to `Firmware/build/<BuildType>/`. Never commit them.
- The `.ioc` file is owned by CubeMX; don't hand-edit unless you know what
  you're undoing on the next regen.
- `CMakeUserPresets.json` is local-only (gitignored). Use it for per-machine
  paths; never `CMakePresets.json`.
